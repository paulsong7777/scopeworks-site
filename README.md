# ScopeWorks Site

Static landing page for https://scope-works.net

## Files

- `index.html`
- `style.css`
- `CNAME`

## GitHub Pages

1. Upload these files to the root of the repository.
2. Go to Repository Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main / root.
5. Custom domain: scope-works.net.
6. Wait for DNS propagation and enable Enforce HTTPS.
