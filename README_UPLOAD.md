# ScopeWorks site final polish upload guide

이 패키지는 scope-works.net 사이트 마감 개선본입니다.

## 포함 파일

- `index.html`
- `imjangbox/index.html`
- `privacy.html`
- `404.html`
- `style-v3.css`
- `sitemap.xml`
- `robots.txt`
- `site.webmanifest`
- `og-image.png`
- `imjangbox/og-image.png`

## 반영 내용

1. 전 페이지 CSS 캐시 버전 `20260608a`로 통일
2. 메인 title/description 한국어 중심으로 정리
3. ImjangBox 전용 OG 이미지 경로 적용
4. 404 페이지를 사이트 톤에 맞게 개선
5. Privacy 페이지를 한국어 개인정보 처리 안내로 개선
6. 모바일 이메일 크기 조정
7. Footer에 대표명 추가
8. sitemap lastmod 갱신

## 업로드 방법

GitHub `scopeworks-site` 레포 루트에 압축 해제된 파일을 그대로 덮어쓰기 업로드하세요.

권장 커밋 메시지:

```text
Polish site metadata, OG images, privacy, and 404 page
```
