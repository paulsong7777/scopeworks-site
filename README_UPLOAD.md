## 반영 내용

1. 한국어 큰 제목의 크기, 자간, 줄간격을 완화했습니다.
2. 메인 페이지의 임장박스 섹션을 회사 사이트 안의 현재 검증 제품처럼 정리했습니다.
3. 임장박스 페이지 문구를 더 실무형으로 다듬었습니다.
4. 영어 중심 Method 문구를 한국어 중심으로 정리했습니다.
5. 모바일에서 제목, 카드, 이메일 영역이 과하게 보이지 않도록 조정했습니다.
6. CSS 캐시 버전을 `20260609a`로 통일했습니다.
7. 기존 OG 이미지는 최신 톤 통일 버전을 유지했습니다.

## 업로드 방법

1. ZIP 압축을 풉니다.
2. GitHub `scopeworks-site` 레포 루트에 파일을 그대로 덮어씁니다.
3. Commit message 예시:

```text
Polish Korean readability and product page tone
```
